# KitsuneTools
Set of tools for Blender that can be useful for assisting on character rigging.  Previously embedded within KitsuneSourceTool

## Blender Version

Atleast 4.5

## Notable Features

### Multi-object weight painting
- Weight paint multiple separate mesh at the same time without the necessity to join

### Node baker
- Bake node outputs to TGA or PNG texture image with selectable sRGB or Non-Color format

### Merging bones or armatures
- Merge bones with their corresponding vertex groups for mesh(es) connected to the armature
- Merge armatures together and matching bone names will be merged to the active armmature

### Apply Armature Pose as Rest Pose or as Shapekeys
- Apply armature's current pose as restpose which also apply the posture for connected mesh(es)
